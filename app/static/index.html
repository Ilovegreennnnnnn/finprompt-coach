What Each Screen Does

            Product map
          

          

            

              
Phoenix Cockpit

              
The home base. It shows runs today, active watchlists, prompt versions, anomalies, lab queue activity, and the strongest opportunity cards.

            

            

              
Opportunity Explorer

              
The market-scanning view. You choose a watchlist, run a research cycle, inspect the idea cards, then read the auto-introspection triggered by that run.

            

            

              
Analyst Chat

              
The single-request mode. Use it when you already know the ticker or question you want to study and you want the tool trace immediately.

            

            

              
Prompt Lab

              
The manual benchmark workspace. It is useful when you want to compare prompt rounds explicitly rather than relying only on the automatic continuous loop.

            

          

        


        

          

            
Recommended Workflow

            Best practice
          

          

            

              
For French market exploration

              
Go to Opportunity Explorer, select France - SBF 120 Core, then click Run Watchlist Scan. This is an editable seed universe built around liquid SBF 120 names on Euronext Paris.

            

            

              
For a focused stock question

              
Go to Analyst Chat and ask something like “Compare AIR.PA and SU.PA on valuation, margins, and balance-sheet risk.”

            

            

              
For prompt governance

              
Watch the candidate prompt in Phoenix Cockpit. If you want a manual sanity check, copy the active prompt into Prompt Lab and run the benchmark.

            

            

              
For anomalies

              
If a metric looks implausible, check the warning flags first. FinPrompt Coach is designed to expose suspicious values instead of hiding them.

            

          

        


        

          

            
How To Read The Numbers

            Metric guide
          

          

            

              
Opportunity Score

              
A research-priority score, not an investment recommendation. It combines valuation, profitability, cash flow quality, balance sheet, market context, and data confidence.

            

            

              
Data Confidence

              
The quality of the underlying data after normalization and anomaly checks. Low confidence means the tool output should be treated carefully.

            

            

              
Reasoning Confidence

              
A confidence proxy for the generated opportunity thesis. It drops when the score is weak, risks are numerous, or the data is noisy.

            

            

              
Promotion / Lab Queue

              
When a run is interesting, ambiguous, or anomalous, it can be promoted into the continuous lab so the prompt system learns from real usage.
